# Máquina de Café (TDD)

**Autores:** Loreni Camila Troncoso Gutiérrez 2025-0064 | Mariely Florian 2025-1184 | Jeremi Aquino 2025-1182

Proyecto Java + JUnit 4 construido a partir de los casos de prueba de la práctica.

- `src/main/java`: Vaso, Cafetera, Azucarero y MaquinaDeCafe.
- `src/test/java`: TestVaso, TestCafetera, TestAzuquero y TestMaquinaDeCafe (10 tests de la máquina).

## Ejecutar
- Maven: `mvn test`
- Eclipse: File > Import > Existing Maven Projects, luego clic derecho > Run As > JUnit Test.
  (Sin Maven: crea un Java Project, copia las carpetas src y agrega JUnit 4 al build path.)
